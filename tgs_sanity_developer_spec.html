Section 01

Project Setup

Sanity has not been configured yet. A Sanctum account exists but no project has been initialised. Complete these steps before any schema or integration work.

1

Initialise Sanity project inside the Next.js repo

Run npm create sanity@latest from the project root. Choose "Add to existing project". This creates a /studio directory inside the existing codebase. Do not create a separate repo.

2

Deploy Studio at /studio

Configure Sanity Studio to be served from theglobalsanctum.com/studio using Next.js routing. This keeps everything under one domain and one deployment. Add CORS origin for the production URL in the Sanity project settings.

3

Install Sanity client in Next.js

Run npm install @sanity/client @sanity/image-url next-sanity. Create a /lib/sanity.js client file — see Section 04.

4

Set environment variables

Add to .env.local and Vercel environment settings: NEXT_PUBLIC_SANITY_PROJECT_ID, NEXT_PUBLIC_SANITY_DATASET (use "production"), SANITY_API_TOKEN (read-only token from Sanity project settings).

5

Grant Kate access to Studio

Invite hello@theglobalsanctum.com as Editor role in the Sanity project dashboard. She should be able to log in at /studio with her Sanity account and create/edit/publish articles independently.

Section 04

Next.js Integration

Two files need to be created: the Sanity client configuration, and the two page routes for the blog index and individual articles.

Sanity Client

/lib/sanity.js

import { createClient } from '@sanity/client' import imageUrlBuilder from '@sanity/image-url' export const client = createClient({ projectId: process.env.NEXT_PUBLIC_SANITY_PROJECT_ID, dataset: process.env.NEXT_PUBLIC_SANITY_DATASET, apiVersion: '2024-01-01', useCdn: process.env.NODE_ENV === 'production', }) const builder = imageUrlBuilder(client) export const urlFor = (source) => builder.image(source)

File Structure

FileRoutePurpose
pages/the-wellness-edit/index.js/the-wellness-editBlog index. Fetches all articles, renders filter tabs and article grid.
pages/the-wellness-edit/[slug].js/the-wellness-edit/[slug]Individual article. Fetches single article by slug. Renders the correct layout template based on the layout field.

Static Generation

Use getStaticProps and getStaticPaths on article pages — not getServerSideProps. This pre-renders articles as static HTML at build time, which is essential for SEO. The Vercel webhook (Section 06) triggers a rebuild when new articles are published.

pages/the-wellness-edit/[slug].js — skeleton

export async function getStaticPaths() { const slugs = await client.fetch(`*[_type == "article"]{ "slug": slug.current }`) return { paths: slugs.map(s => ({ params: { slug: s.slug } })), fallback: 'blocking' // ISR: new articles appear without full rebuild } } export async function getStaticProps({ params }) { const article = await client.fetch(ARTICLE_QUERY, { slug: params.slug }) if (!article) return { notFound: true } return { props: { article }, revalidate: 60 } }

Section 05

GROQ Queries

Store all queries in /lib/queries.js. Import into page files — do not write inline queries inside components.

All articles (blog index)

export const ALL_ARTICLES_QUERY = ` *[_type == "article"] | order(publishedAt desc) { title, "slug": slug.current, category, layout, excerpt, publishedAt, readTime, heroImage, author }`

Articles by category (tab filter)

export const ARTICLES_BY_CATEGORY_QUERY = ` *[_type == "article" && category == $category] | order(publishedAt desc) { title, "slug": slug.current, category, layout, excerpt, publishedAt, readTime, heroImage, author }` // Pass category slug as parameter: client.fetch(ARTICLES_BY_CATEGORY_QUERY, { category: 'philosophy' })

Single article (article page)

export const ARTICLE_QUERY = ` *[_type == "article" && slug.current == $slug][0] { title, "slug": slug.current, category, layout, heroImage, excerpt, author, publishedAt, readTime, body, tags, gallery, keyFacts, venueLink, ctaText, ctaLink, badge, seoTitle, seoDescription, ogImage, "relatedArticles": relatedArticles[]-> { title, "slug": slug.current, category, excerpt, heroImage, publishedAt } }`

Section 06

Vercel Webhook

Without a webhook, publishing a new article in Sanity will not trigger a site rebuild and the article will not appear live. This takes approximately 15 minutes to configure.

1

Get the Vercel Deploy Hook URL

In Vercel project settings → Git → Deploy Hooks. Create a new hook named "Sanity Publish". Copy the generated URL.

2

Add webhook in Sanity

In Sanity project settings → API → Webhooks. Create new webhook. Paste the Vercel URL. Set Filter to _type == "article". Enable on events: Create, Update, Publish, Unpublish.

3

Test end-to-end

Publish a draft article in Studio. Verify a new deployment is triggered in Vercel. Confirm the article URL resolves within 60 seconds.

ISR Note

With fallback: 'blocking' and revalidate: 60 set in getStaticProps, new articles will also appear without a full rebuild via Incremental Static Regeneration. The webhook is still recommended for immediate propagation.

Section 07

Layout Templates

Five layout templates share a common base structure. Build one ArticleLayout component that conditionally renders layout-specific sections based on the article's layout field value. All five share: nav, breadcrumb, category eyebrow, title, author/date/read time line, excerpt, body (Portable Text), tags, related articles, and footer.

Layout 1 — editorial

Long-Form Editorial

PhilosophyHorizons PracticesPathways

The default template. Full-width hero image (1200×600), large title, excerpt, rich body with headings, pull quotes, inline images. The base all other layouts extend.

Layout 2 — profile

Profile & Spotlight

Portraits

Same as Layout 1 plus: Key Facts card (structured sidebar block), photo gallery grid (2×2), and Venue Link CTA button. Used for venue features and facilitator interviews.

Layout 3 — guide

Practical Guide

The CompassThe Craft

Shorter hero (1200×400). Body structured as numbered steps via H3 headings. Tip/Callout boxes. Optional comparison table. CTA button at end.

Layout 4 — data

Data & Insights

Pulse

No hero image. Opens with a 3-up stat card row (built from Canva-exported images or a custom stats block). Charts/visualisations as image blocks. Source citations in small italic text at foot.

Layout 5 — short-form

Short-Form / Announcement

The Sanctum

No hero. Optional badge above title (Platform Update, Milestone, etc). Short body — paragraphs only, no H2 sections. Optional single CTA button. 300–600 words.

Layout Switching Logic

pages/the-wellness-edit/[slug].js — layout switch

import EditorialLayout from '@/components/article/EditorialLayout' import ProfileLayout from '@/components/article/ProfileLayout' import GuideLayout from '@/components/article/GuideLayout' import DataLayout from '@/components/article/DataLayout' import ShortFormLayout from '@/components/article/ShortFormLayout' const LAYOUTS = { editorial: EditorialLayout, profile: ProfileLayout, guide: GuideLayout, data: DataLayout, 'short-form': ShortFormLayout, } export default function ArticlePage({ article }) { const Layout = LAYOUTS[article.layout] || EditorialLayout return <Layout article={article} /> }
