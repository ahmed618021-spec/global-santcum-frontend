Image Implementation Brief

This document specifies every image replacement required across the TGS platform. All images have been selected, filtered, and prepared by Kate and are available in the shared Google Drive folder. Please implement each image exactly as specified below.

Critical Requirement

All images must display at high resolution and high quality across all devices and screen sizes. No image should appear blurred, pixelated, or compressed. Please ensure correct implementation of image optimisation — use high-res source files, appropriate srcset attributes where applicable, and ensure images are rendered at full quality. Do not reduce image quality during implementation.
